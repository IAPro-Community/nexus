Defect and fix
- Reproduction: Overview cards for active shell runtimes called onProjectShell(), which dispatches creation of a new shell. A native restart test showed the runtime total grow from two to three after pressing “Anexar Terminal”.
- Correction: ProjectOverviewSurface now requires an explicit onAttachRuntime callback and sends the selected RuntimeSession to it. WorkspaceSurfaceHost opens projectShellSurface with the existing runtime_id, then focuses the Terminals surface. Agent cards keep using their existing agent terminal route. Creating a new shell stays on the separate “Terminal do Projeto” action.
- Regression: overviewRuntimeActions.test.ts covers both existing shell attachment and existing agent-runtime routing. The test was first run before implementation and failed because the attachment action module did not exist; after implementation, 2/2 passed.
