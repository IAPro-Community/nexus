Controlled native HUD attention fixture

This was a local test fixture, not an event emitted by an external agent.
The Nexus HUD Wails binary ran with HOME, XDG_CONFIG_HOME, XDG_DATA_HOME,
NEXUS_CONFIG_DIR, and NEXUS_DATA_DIR rooted under:
/tmp/nexus-linux-100-attention-fixture-20261025

A test project and a MissionRun were inserted into the isolated Nexus SQLite
profile. The run used state BLOCKED_NEEDS_USER and one valid actionable human
intervention. The real embedded Core then exposed it through the authenticated
GET /api/v1/attention endpoint as level REQUIRE_USER. The HUD displayed the
attention balloon next to the single NEX mascot.

Native XTest clicked “Adiar”. The balloon closed and the HUD returned from
310x245 to 224x158. A second authenticated query still returned HTTP 200 and
one needs_you item for the fixture, confirming that snooze only hides the HUD
notification and does not delete the canonical Attention Center task.
