NEX — seis vistas em 256 px

Toque em qualquer vista para conferir a imagem em 256 pixels nativos e amplie até 2× para enxergar o detalhamento. Ampliação não cria novos pixels; o objetivo é descobrir defeitos antes de produzir o atlas oficial.

Não é um giro 360° completo. Estas seis artes foram geradas de forma independente. Faltam perfis verdadeiros, vistas traseiras intermediárias, fundo transparente e geometria aprovada entre frames. O HUD e a homepage oficial permanecem inalterados.
