# Glossário

Esta página é uma entrada curta para o [glossário técnico completo](GLOSSARY.md).

| Termo | Significado no Nexus |
| --- | --- |
| Agent | identidade persistente com papel, especialidade e histórico operacional. |
| Runtime | recurso transitório que executa uma sessão de provider. |
| Provider | integração com uma CLI/serviço de coding agent. |
| Profile | configuração/autenticação local de um provider. |
| Direct | fluxo simples: projeto, sessão, provider e terminal. |
| Composer | refinamento de intenção e geração de brief/prompt. |
| WorkPlan / Flow | plano de trabalho e sua projeção visual/editável. |
| Mission | execução coordenada com dependências, gates e evidências. |
| Lead Agent | Agent em primeiro plano que mantém o objetivo e integra trabalho delegado. |
| Evidence | registro verificável de validação, não uma inferência de sucesso. |
