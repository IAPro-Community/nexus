## O que é considerado uso comercial?

A licença concede permissões específicas e contém exceções para determinadas organizações. Não presumir que *toda atividade corporativa* ou *toda instituição financiada* seja automaticamente proibida; consulte os itens “Noncommercial Purposes”, “Personal Uses” e “Noncommercial Organizations” do texto integral. Para casos não cobertos, solicite autorização comercial separada ao titular dos direitos.

O projeto não oferece por esta licença permissão para redistribuir builds, versões modificadas ou produtos concorrentes baseados em alterações do source. **A licença não impede tecnicamente cópias**; as restrições são jurídicas.

## GitHub e forks

Um repositório público pode ser visualizado e bifurcado no GitHub nos limites dos Termos de Serviço da plataforma. Isso não equivale a autorização geral para modificar, republicar, sublicenciar ou comercializar o software. Se o objetivo for impedir qualquer cópia técnica, **não publique o código**.

- [Termos beta históricos](BETA_TERMS.md) são mantidos para contexto de distribuição anterior. Não constituem autorização para publicar artefatos novos.

## Contribuições

A licença **não autoriza o público a modificar o Nexus**, inclusive por meio de PRs. Durante a fase inicial são bem-vindos relatos, sugestões e documentação descritiva via issues; patches de terceiros exigem autorização/contribuição jurídica separada antes de serem solicitados ou integrados. Leia [CONTRIBUTING](../../CONTRIBUTING.md).

## Marca e exploração comercial

A disponibilização do código não licencia a marca, logotipo, nomes comerciais ou identidade visual do Nexus. Para redistribuição, integração comercial, customização ou licenciamento empresarial, obtenha autorização escrita específica do titular. Este repositório não contém, por si só, uma oferta de licença comercial.
