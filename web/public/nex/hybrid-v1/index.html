NEX — Hero híbrido fiel à arte original

Este protótipo usa os próprios pixels do PNG como fonte. Os efeitos movimentam camadas recortadas sem reconstruir o rosto, capacete ou materiais em SVG. As ações são visuais; não simulam telemetria real.

Idle · Movimento mínimo
Os módulos usam as âncoras originais; pixels sob olhos e módulos são preenchimentos de restauração para permitir gestos. Arte em camadas ainda exige aprovação humana. O modo reduzido respeita o sistema operacional. Não contém rotação 360°, atlas retro por frames, integração com Core ou validação do HUD nativo.
